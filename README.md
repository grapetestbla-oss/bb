# APEX SETUPS — магазин сетапов для F1 25

Интернет-магазин готовых сетапов для игры **F1 25** и **2026 Season Pack**,
а также заявок на индивидуальное обучение.

## Возможности

- **Каталог сетапов** по всем трассам игры (F1 25, классические трассы, 2026 Season Pack).
  Фильтры по пакету, типу (квалификация / гонка / дождь / тайм-триал) и трассе.
- **Регистрация и вход**: без аккаунта покупка недоступна. Сессия — подписанная httpOnly-cookie.
- **Покупка сетапа**: параметры машины (21 значение) скрыты до подтверждения оплаты,
  после оплаты доступны на странице сетапа и в личном кабинете навсегда.
- **Обучение**: покупка программы оформляется как заявка с анкетой —
  связь (Telegram / Discord), платформа (PC / PlayStation / Xbox),
  устройство управления (руль / геймпад / клавиатура), уровень и комментарий.
  Заявка падает в панель администратора с уведомлением, там её можно «взять в работу».
- **Панель администратора** (`/admin`, только для роли `admin`):
  обзор и выручка, CRUD сетапов, трассы, заказы (подтверждение оплаты вручную),
  заявки на обучение, программы обучения, пользователи, уведомления,
  подключение платёжных систем.
- **Платёжные системы**: FreeKassa и Platega подключаются прямо из панели
  (ключи хранятся в БД и не отдаются на клиент), плюс режим ручного подтверждения.

## Запуск

```bash
bun install
bun run db:push        # создать SQLite-базу
bun run dev            # http://localhost:3000
curl -X POST http://localhost:3000/api/seed   # трассы, сетапы, программы обучения, админ
```

Переменные окружения (`.env`):

```
DATABASE_URL=file:../db/custom.db
AUTH_SECRET=<случайная строка для подписи сессий>
```

## Платёжные вебхуки

| Система   | URL уведомления                  |
|-----------|----------------------------------|
| FreeKassa | `POST /api/payments/freekassa`   |
| Platega   | `POST /api/payments/platega`     |

FreeKassa проверяется по подписи `md5(merchant_id:amount:secret2:order_id)`,
Platega — по заголовкам `X-MerchantId` / `X-Secret`.
