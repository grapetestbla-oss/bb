# F1 Icons League

Сайт киберспортивной лиги по игре **F1 25**: новости, календарь сезона, личный и командный зачёт,
приём заявок, личный кабинет пилота и полноценная админ-панель.

## Возможности

**Для гостей и пилотов**
- Главная с ближайшим этапом, топом зачёта и новостями
- Новости лиги (список + страница новости)
- Календарь сезона со статусами этапов, временем старта и подиумом прошедших гонок
- Таблица зачёта: личный (очки, победы, подиумы, поулы, быстрые круги) и командный
- Страница команд с составами и очками, страница регламента с системой начисления очков
- Регистрация и вход, подача заявки в лигу
- **Личный кабинет**: статус участия (команда, номер, место в зачёте), личные результаты по этапам,
  история заявок с комментарием администрации, редактирование профиля и смена пароля

**Админ-панель** (`/admin`, вкладки)
- **Заявки** — одобрение/отклонение с назначением команды и номера; при одобрении пилот автоматически
  добавляется в состав сезона. Комментарий администрации виден пилоту в кабинете
- **Сезоны** — создание, редактирование, назначение текущего, система очков (JSON-массив + очки за
  быстрый круг и поул), открытие/закрытие приёма заявок, регламент, удаление
- **Команды** — создание (в т.ч. быстрое добавление классических команд), цвет, аббревиатура,
  ручная корректировка очков команды, порядок, удаление
- **Пилоты** — распределение по командам, номера, статус (основной состав / резерв / не выступает),
  штрафы и бонусы очков, исключение из сезона
- **Календарь** — создание и редактирование этапов (номер, трасса, страна, дата/время, круги, статус,
  ссылка на трансляцию, заметка), удаление
- **Результаты и зачёт** — протокол этапа: позиции, поул, быстрый круг, DNF, штрафные очки.
  Очки считаются автоматически по системе сезона, любое значение можно переопределить вручную
- **Новости** — создание, редактирование, черновик/публикация, закрепление, удаление
- **Пользователи** — назначение администраторов, блокировка, сброс пароля, удаление аккаунта

## Роли

| Роль | Права |
|------|-------|
| `USER` | Заявка в лигу, личный кабинет |
| `ADMIN` | Вся админ-панель, кроме назначения ролей и удаления аккаунтов |
| `SUPERADMIN` | Всё, включая назначение и снятие администраторов |

Главный администратор создаётся сид-скриптом:

```
логин:  F1Icons_Admin
пароль: F1Icons_Admin(cloud)
```

Пароль можно изменить в личном кабинете (раздел «Настройки профиля»), а логин/пароль стартового
администратора — переменными `SEED_ADMIN_LOGIN` и `SEED_ADMIN_PASSWORD` при первом запуске сида.

## Запуск

```bash
bun install
cp .env.example .env      # DATABASE_URL для SQLite
bun run setup             # prisma generate + db push + сид (админ, сезон, команды, календарь)
bun run dev               # http://localhost:3000
```

Продакшен:

```bash
bun run build
bun run start
```

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui · Prisma + SQLite ·
собственная сессионная авторизация (bcrypt + httpOnly-cookie).

```
                              Application, News

src/lib/auth.ts               сессии, хеширование паролей, текущий пользователь
src/lib/api.ts                guard-хелперы для API (user / admin / superadmin)
src/lib/points.ts             расчёт очков за гонку
src/lib/standings.ts          сборка личного и командного зачёта
src/app/api/…                 REST-маршруты (auth, profile, applications, admin/*)
src/app/…                     страницы сайта, /cabinet, /admin
src/components/admin/…        вкладки админ-панели
```
