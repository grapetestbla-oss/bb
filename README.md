# FANTASTIQUEBOY SETUPS — магазин сетапов для F1 25

Интернет-магазин готовых сетапов для игры **F1 25** и **2026 Season Pack**,
а также заявок на индивидуальное обучение.

## Возможности

- **Каталог сетапов** по всем трассам игры (F1 25, классические трассы, 2026 Season Pack).
  Один товар на трассу от конкретного пилота; квалификация и гонка не разделяются,
  внутри лежат варианты по условиям: сухо и дождь. Тайм-триал не продаётся — эти
  сетапы в открытом доступе. Фильтры по игре, пилоту и трассе.
- **Пилоты и паки**: сетапы принадлежат пилотам-авторам, у каждого свой почерк настройки.
  Пак по игре открывает все трассы пилота в F1 25 или в 2026 Season Pack, а отдельный
  **фулл пак** (`game: "all"`) — обе игры сразу, включая новые трассы и обновления.
- **Регистрация и вход**: без аккаунта покупка недоступна. Сессия — подписанная httpOnly-cookie.
- **Покупка сетапа или пака**: параметры машины (21 значение на каждый вариант) скрыты до
  подтверждения оплаты, после оплаты доступны на странице сетапа и в личном кабинете навсегда.
  Купленный пак открывает все входящие в него сетапы.
- **Обучение**: покупка программы оформляется как заявка с анкетой —
  связь (Telegram / Discord), платформа (PC / PlayStation / Xbox),
  устройство управления (руль / геймпад / клавиатура), уровень и комментарий.
  Заявка падает в панель администратора с уведомлением, там её можно «взять в работу».
- **Панель администратора** (`/admin`, только для роли `admin`):
  обзор и выручка, CRUD сетапов с редактором вариантов, пилоты, паки, трассы,
  заказы (подтверждение оплаты вручную),
  заявки на обучение, программы обучения, пользователи, уведомления,
  подключение платёжных систем.
- **Платёжные системы**: FreeKassa и Platega подключаются прямо из панели
  (ключи хранятся в БД и не отдаются на клиент), плюс режим ручного подтверждения.
- **Соцсети** выводятся в шапке и подвале, ссылки редактируются в панели
  (вкладка «Платежи»); значения по умолчанию — в `src/lib/socials.ts`.

## Владелец магазина

Аккаунтов в базе изначально нет. **Панель управления получает тот, кто
зарегистрируется на сайте первым** — на форме регистрации, пока магазин пуст,
об этом написано прямо. Все последующие регистрации создают обычных покупателей.

Роль выдаётся в одной транзакции с созданием пользователя, поэтому две
одновременные регистрации не могут получить админку обе.

Логин, email и пароль меняются в личном кабинете → вкладка «Профиль».

### Скрытый служебный аккаунт (root)

Сид создаёт резервного главного администратора `root` / `password1337`. Это
полноценный админ, но с флагом `hidden`: он не показывается во вкладке
«Пользователи», не попадает в счётчики панели и не мешает правилу «первый
зарегистрировавшийся — владелец» (в подсчёте владельцев скрытые аккаунты
игнорируются). Нужен как запасной вход, если доступ к основному аккаунту потерян.

Логин и пароль переопределяются переменными окружения `ROOT_LOGIN`,
`ROOT_PASSWORD`, `ROOT_EMAIL` (см. `src/lib/root-admin.ts`). **На боевом сервере
задайте свой `ROOT_PASSWORD`** в `.env` до первого запуска сида.

## Запуск

```bash
bun install
bun run db:push        # создать SQLite-базу
bun run dev            # http://localhost:3000
curl -X POST http://localhost:3000/api/seed   # трассы, программы обучения, настройки
```

Сид не создаёт ни аккаунтов, ни сетапов с паками: зарегистрируйтесь первым,
чтобы получить панель, и наполняйте каталог вручную —
«Пилоты» → «Сетапы» (трасса + варианты «сухо» и «дождь») → «Паки».

Переменные окружения (`.env`):

```
DATABASE_URL=file:../db/custom.db
AUTH_SECRET=<случайная строка для подписи сессий>
```

## Платёжные вебхуки

| Система   | URL уведомления                  |
|-----------|----------------------------------|
| FreeKassa | `POST /api/payments/freekassa`   |
| Platega   | `POST /api/payments/platega`     |

FreeKassa проверяется по подписи `md5(merchant_id:amount:secret2:order_id)`,
Platega — по заголовкам `X-MerchantId` / `X-Secret`.

## Развёртывание на сервере

Скрипт `deploy/deploy.sh` ставит Node.js, Bun и Caddy, собирает проект,
поднимает systemd-сервис на `127.0.0.1:3000` и настраивает фронт:

```bash
scp fantastiqueboy-setups.tar.gz root@SERVER:/root/
ssh root@SERVER
mkdir -p /opt/fantastiqueboy-setups
tar -xzf /root/fantastiqueboy-setups.tar.gz -C /opt/fantastiqueboy-setups
cd /opt/fantastiqueboy-setups && bash deploy/deploy.sh [домен]
```

Подробности и обновление версии — в `deploy/README.md`.
