# Публикация сайта в интернете

Сайт — это приложение с сервером и базой данных, поэтому «просто закинуть файлы» не получится:
нужен хостинг, который умеет запускать Node.js, и база данных.

Ниже — бесплатный вариант, который занимает 5–10 минут: **Vercel** (хостинг) + **Neon** (PostgreSQL).
Оба сервиса имеют бесплатные тарифы без привязки карты, домен вида `ваш-проект.vercel.app`
выдаётся сразу.

> **Важно про базу.** Локально проект работает на SQLite — это файл на диске.
> На бесплатных хостингах диск не сохраняется между перезапусками, поэтому там нужен PostgreSQL,
> иначе все аккаунты, заявки и таблицы зачёта будут пропадать. Проект поддерживает обе базы:
> тип определяется автоматически по строке подключения в `DATABASE_URL`, менять код не нужно.

## Вариант 1. Vercel + Neon (рекомендуется)

1. **Импортируйте проект.** Самый быстрый способ — кнопка
   [Deploy with Vercel](https://vercel.com/new/clone?repository-url=https://github.com/grapetestbla-oss/bb/tree/claude/f1-icons-league-site-jst0uo):
   Vercel скопирует ветку с сайтом в ваш GitHub и создаст проект.

   Если предпочитаете работать со своим репозиторием напрямую: слейте ветку
   `claude/f1-icons-league-site-jst0uo` в `main` (Vercel по умолчанию собирает главную ветку) либо после импорта
   укажите ветку вручную в *Settings → Git → Production Branch*.
   Настройки сборки менять не нужно — проект сам подхватит `vercel-build`.

3. **Подключите базу данных.** В проекте откройте вкладку **Storage → Create Database →
   Neon (Serverless Postgres)**, тариф Free. Vercel сам добавит в проект переменные
   `DATABASE_URL` и `DATABASE_URL_UNPOOLED` — больше ничего вписывать не нужно.

   Если первый деплой упал с ошибкой «Не задана переменная окружения DATABASE_URL» — это нормально:
   база ещё не была подключена. Нажмите **Redeploy** после подключения Neon.

4. **Готово.** При сборке автоматически создаются таблицы и стартовые данные:
   главный администратор, сезон, 10 команд, календарь и приветственная новость.

5. **Сразу смените пароль администратора.** Зайдите на `/login` под
   `F1Icons_Admin` / `F1Icons_Admin(cloud)` и поменяйте пароль в личном кабинете
   («Настройки профиля»).

   Либо задайте свой пароль **до первого деплоя**: *Settings → Environment Variables* →
   `SEED_ADMIN_PASSWORD` = ваш пароль (и при желании `SEED_ADMIN_LOGIN` = ваш логин).

### Что дальше

- Каждый `git push` в главную ветку автоматически пересобирает сайт.
- Свой домен: *Settings → Domains* (бесплатно, если домен уже куплен).
- Бесплатные лимиты: Vercel Hobby — для личных некоммерческих проектов;
  Neon Free — 0.5 ГБ базы, чего хватит на многие сезоны лиги.

## Вариант 2. Render

В репозитории есть готовый `render.yaml`.

1. Создайте базу PostgreSQL (тот же [Neon](https://neon.tech), бесплатный тариф).
2. На [render.com](https://render.com) → **New → Web Service** → выберите репозиторий,
   тариф **Free**.
3. В переменных окружения укажите `DATABASE_URL` (строка подключения из Neon).
   Если провайдер даёт отдельное прямое подключение — добавьте его как `DIRECT_URL`.

Особенность бесплатного тарифа Render: сервис засыпает после 15 минут без запросов,
первый заход после простоя открывается ~30 секунд. На Vercel такого нет.

## Вариант 3. Свой сервер или VPS (Docker)

```bash
docker build -t f1-icons-league .
docker run -d -p 3000:3000 \
  -e DATABASE_URL="postgresql://user:password@host:5432/f1icons" \
  f1-icons-league
```

Миграции и стартовые данные применяются при запуске контейнера.
Для SQLite (данные в примонтированном томе) соберите образ так:

```bash
docker build --build-arg DATABASE_URL="file:../db/f1icons.db" -t f1-icons-league .
docker run -d -p 3000:3000 -v f1icons-db:/app/db \
  -e DATABASE_URL="file:../db/f1icons.db" f1-icons-league
```

## Переменные окружения

| Переменная | Обязательна | Назначение |
|------------|-------------|------------|
| `DATABASE_URL` | да | Строка подключения: `postgresql://…` на хостинге или `file:…` локально |
| `DIRECT_URL` / `DATABASE_URL_UNPOOLED` | нет | Прямое подключение для миграций, если база работает через пул соединений |
| `SEED_ADMIN_LOGIN` | нет | Логин главного администратора при первом заполнении базы (по умолчанию `F1Icons_Admin`) |
| `SEED_ADMIN_PASSWORD` | нет | Его пароль (по умолчанию `F1Icons_Admin(cloud)`) |

## Если что-то пошло не так

- **Сборка падает с «SQLite не подходит для хостинга»** — не подключена база PostgreSQL,
  переменная `DATABASE_URL` всё ещё указывает на файл.
- **Ошибка про advisory lock или пул при миграции** — добавьте `DIRECT_URL`
  с непуловой строкой подключения (у Neon это `DATABASE_URL_UNPOOLED`).
- **Сайт открывается, но вход не работает** — проверьте, что домен открывается по `https`:
  сессионная кука в продакшене помечена как `secure`.
